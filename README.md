# 🎬 MovieInsight-Agent

An AI-powered movie information extraction agent that converts unstructured movie descriptions into structured insights using **Mistral AI, LangChain, Pydantic, and Streamlit**.

MovieInsight-Agent uses Large Language Models (LLMs) to understand natural language movie descriptions and extract important metadata such as movie title, release year, genre, director, cast, rating, and summary.

---

## 🚀 Features

✨ **AI-Powered Information Extraction**
- Extract meaningful movie details from plain text using Mistral AI.

🧠 **LLM-Based Processing**
- Uses LangChain to design prompts and interact with the language model.

📦 **Structured Output**
- Uses Pydantic Output Parser to generate validated structured responses.

🎨 **Interactive Web Interface**
- Built with Streamlit for a clean and user-friendly experience.

📊 **Movie Insights**
- Displays:
  - Movie title
  - Release year
  - Genre
  - Director
  - Cast members
  - IMDb rating
  - Story summary

📄 **JSON Output**
- View extracted movie information in structured JSON format.
